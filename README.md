## 日本VPS的線路門道：CN2、軟銀、IIJ 分別是什麼

線路決定了同一台東京伺服器，在你手機上的延遲可能差出一倍以上。日本離中國大陸近，東京機房的物理延遲本來就比美西低一大截，對電信、聯通、移動三網也相對友好，但「機房在東京」不代表走的路都一樣。

目前市面上常見的幾種：

- **CN2 GIA**：電信的高端線路。搬瓦工的東京 CN2 GIA 機房有第三方實測延遲低至 51ms、原生 IP，頻寬記錄可到 1.2Gbps，被測評站稱為日本高速 VPS 的天花板——價格也是天花板等級。
- **軟銀（Softbank）**：搬瓦工大阪、LOCVPS 東京等主打的路線，賣點是三網往返直連。LOCVPS 東京的年付特價機 499 元人民幣、300Mbps 頻寬。
- **IIJ**：vmiss 的東京、大阪節點預設接入 IIJ 網路、1Gbps 頻寬（往期促銷曾低至約 18 元人民幣／月），akilecloud 的 JPIIJ-Lite 套餐也走 IIJ。
- **NTT**：HostDare 的東京 NKVM 機房走 NTT 網路。

購買前驗證線路的方法很簡單：各商家都提供測試 IP，先 ping 一遍看延遲；有 looking glass 的話，用 traceroute 看回程，一旦出現繞路、非直連，就要對延遲多留個心眼。

還有一點先說在前頭：這些優化線路基本都出現在年付中小商家身上。Vultr、AWS 這類國際大廠不靠大陸直連競爭，官方頁面也不會給你標 CN2、軟銀的字樣——這會直接影響後面的選擇。

## 挑日本VPS前，先弄清這三件事

下面三件事決定你會不會買到一台「帳面好看、用起來難受」的機器，也是多數推薦文一筆帶過的地方。

**第一，機房在日本，不等於大陸訪問快。** 繞不繞路看路由，不看地圖。同樣掛著東京的名號，Evoxt 東京 2.99 美元一個月確實便宜，但第三方實測三網繞路、延遲偏高；而 StarryDNS 東京實測三網往返直連、延遲低。差別全在線路，下單前務必用測試 IP 驗證。

**第二，年付便宜的前提，是你確定要用滿一年。** 各家退款政策差距很大：搬瓦工的日本促銷套餐提供 30 天退款保證，StarryDNS 只給新用戶首台 3 天退款，更多低價年付方案到期前基本拿不回錢。拿不準的話，先月付跑一段時間再說。

**第三，想清楚你要的是機房 IP 還是住宅 IP。** 做 TikTok 日區運營、解鎖日本本土串流服務，普通機房 IP 容易被風控，第三方實測也顯示部分東京節點（例如 V5 Server 東京）非原生 IP、串流解鎖能力偏弱。這類需求對口的產品是 ISP 住宅 IP／家寬類型的日本 VPS，例如麗薩主機的雙 ISP 家寬、ByteVirt 的日本家寬款、IPRaft 的原生雙 ISP 套餐——和普通 VPS 是兩種不同的產品，選的時候別混。
